**ASCII ⛶ VISOR**는 웹캠이나 다른 영상 소스를 실시간 ASCII 아트로 바꾸는 [OBS Studio](https://obsproject.com/)용 영상 필터 플러그인입니다. 문자, 색상, 밀도를 선택하고 장면에 맞게 화면을 조절하세요. 결과가 미리보기에 바로 나타나며 녹화와 방송에도 적용됩니다.

개성 있는 카메라 화면, 창의적인 방송, 음악 공연, 영상 실험에 활용하세요.

ASCII 아바타는 VTuber 스타일의 방송 표현을 위한 또 다른 선택지입니다. 일반적인 웹캠 화면 대신 스타일화된 모습을 보여 주면서 움직임과 반응을 실시간으로 전달할 수 있습니다. 시각적인 프라이버시를 어느 정도 지킬 수 있지만 익명성을 보장하지는 않습니다. 목소리, 실루엣, 화면 속 세부 요소로 알아볼 수 있습니다.

## ✨ 주요 기능

| 기능 | 활용 |
|---|---|
| **기본 세트 8개** | 클래식 ASCII, 다양한 문자와 기하학적 모양으로 질감을 바꿉니다. |
| **사용자 지정 문자** | 원하는 문자 세트를 입력해 자신만의 스타일을 만듭니다. |
| **색상 팔레트 20개** | 기본 스타일이나 원하는 색상을 선택합니다. |
| **색상 스타일 저장** | 필터마다 사용자 색상 프리셋을 최대 20개 저장합니다. |
| **투명 배경** | 문자 사이를 투명하게 만들어 게임이나 영상 위에 겹칩니다. |
| **화면 조절** | 밀도, 대비, 감마, 검정·흰색 레벨, 크기와 위치를 조절합니다. |
| **OBS 안에서 사용** | 기본 필터 창에서 조절하고 녹화와 방송에 사용합니다. |

밀도는**가로 30~150문자**입니다. 문자 세트와 팔레트는 자유롭게 조합할 수 있습니다.

### 🎨 색상 스타일

같은 영상에도 다른 분위기를 줄 수 있습니다. 팔레트를 바꾸거나 문자와 배경색을 직접 선택하세요.

https://github.com/user-attachments/assets/30c21fb0-9aad-4652-9b45-b2c97a04a234

### 🔤 문자 세트와 사용자 입력

좋아하는 팔레트를 유지하면서 **8개 세트**를 골라 보세요. 클래식 ASCII, 다양한 문자 체계, 숫자와 기하학적 모양이 서로 다른 질감을 만듭니다.

https://github.com/user-attachments/assets/8ed8da50-d899-492f-a81a-4ccff01a9210

나만의 화면을 원하나요? **직접 입력**을 선택하고 원하는 문자를 입력하세요. 조합을 바꾸며 자신만의 스타일을 찾아보세요.

https://github.com/user-attachments/assets/067aa13c-cada-4ff3-859d-4025b0b72c82

### 🎛️ 실시간 설정

조명과 장면 속 카메라 크기에 맞춰 밀도와 명암을 조절하세요. 변경 사항은 미리보기에 즉시 반영됩니다.

https://github.com/user-attachments/assets/772cb41e-769f-432c-b734-f8f910bb3957

### 🫧 장면에 어울리는 투명 배경

투명 배경에서는 문자 사이로 게임, 영상, 다른 소스가 보입니다. ASCII 카메라를 방송 화면에 자연스럽게 배치할 수 있습니다.

투명해지는 부분은 문자 사이의 공간입니다. 사람과 방 배경을 자동으로 분리하는 기능은 아닙니다.

https://github.com/user-attachments/assets/7efa18ca-853b-4c0f-a8cb-d59d1732bf57

## 💻 호환성

Windows x64, Linux x86_64 (Ubuntu 24.04 / glibc 2.39 이상), macOS universal (Apple Silicon 및 Intel). OBS는 별도 설치해야 합니다. OBS 32.2.2에서 테스트합니다. macOS는 임시 서명이며 공증되지 않았습니다. Linux Flatpak에는 호환되는 OBS 런타임이 필요합니다. 자세한 내용은 안내를 참조하세요.
