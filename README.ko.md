**ASCII ⛶ VISOR**는 웹캠이나 다른 영상 소스를 실시간 ASCII 아트로 바꾸는 [OBS Studio](https://obsproject.com/)용 영상 필터 플러그인입니다. 문자, 색상, 밀도를 선택하고 장면에 맞게 화면을 조절하세요. 결과가 미리보기에 바로 나타나며 녹화와 방송에도 적용됩니다.

개성 있는 카메라 화면, 창의적인 방송, 음악 공연, 영상 실험에 활용하세요.

## ✨ 주요 기능

| 기능 | 활용 |
|---|---|
| **기본 세트 10개** | 클래식 ASCII, 다양한 문자와 기하학적 모양으로 질감을 바꿉니다. |
| **사용자 지정 문자** | 원하는 문자 세트를 입력해 자신만의 스타일을 만듭니다. |
| **색상 팔레트 20개** | 기본 스타일이나 원하는 색상을 선택합니다. |
| **색상 스타일 저장** | 필터마다 사용자 색상 프리셋을 최대 20개 저장합니다. |
| **투명 배경** | 문자 사이를 투명하게 만들어 게임이나 영상 위에 겹칩니다. |
| **화면 조절** | 밀도, 대비, 감마, 검정·흰색 레벨, 크기와 위치를 조절합니다. |
| **OBS 안에서 사용** | 기본 필터 창에서 조절하고 녹화와 방송에 사용합니다. |

밀도는**가로 30~150문자**입니다. 문자 세트와 팔레트는 자유롭게 조합할 수 있습니다.

### 🫧 장면에 어울리는 투명 배경

투명 배경에서는 문자 사이로 게임, 영상, 다른 소스가 보입니다. ASCII 카메라를 방송 화면에 자연스럽게 배치할 수 있습니다.

문자 사이의 빈 공간을 투명하게 만드는 기능이며 사람과 방을 자동으로 분리하지는 않습니다. 겹치기 시연 영상은 추후 추가합니다.

## 🚀 빠른 시작

1. 위 링크 또는 릴리스의 **Assets**에서 **ASCII-VISOR-0.2.7-Setup.exe**를 다운로드하세요.
2. OBS 창을 모두 닫고 설치 프로그램을 실행하세요.
3. **일반 OBS / Steam — 공통 설치**를 선택하세요. 포터블 OBS는 해당 옵션과 폴더를 선택하세요.
4. OBS를 열고 카메라나 다른 영상 소스를 선택하세요.
5. 소스 우클릭 → **필터 → 효과 필터 → + → ASCII ⛶ VISOR**.
6. 필터 목록에서 플러그인 이름을 클릭해 설정을 여세요. 문자, 색상, 밀도를 취향대로 바꾸며 즐겁게 실험해 보세요!

https://github.com/user-attachments/assets/6e653001-9286-4655-aad6-fa029b3f2180

눈 아이콘으로 원본 영상과 비교할 수 있습니다. 설정 창을 닫아도 효과가 유지되며 OBS를 재시작해도 설정이 저장됩니다.
