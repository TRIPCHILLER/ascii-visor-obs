# Changelog

## 0.2.8 — 2026-10-13

- Fixed transparent backgrounds appearing as black rectangles over other scene sources. Fresh and cached frames now use the same premultiplied-alpha compositing.
- Added a regression test for compositing over a background source.
- Added the transparency demonstration and ASCII-avatar use case to all ten README languages.
- Fonts, character sets and default character stability are unchanged.
