# Материалы версии 0.2.0

Алгоритмы и наборы — авторские исходники TRIPCHILLER, перенесены с разрешения автора. Новый код фильтра и shader подготовлены для распространения под GPL-2.0-or-later, текст в LICENSE. Исходный backend, интерфейс WebApp и пользовательские данные не входят в пакет.

Better VCR: copyright artdzyk, 2022–2024; в исходном файле nameID 13 указана Open Font License. Неизменённая копия TTF, copyright и текст SIL OFL 1.1 находятся в data/fonts.

Noto Sans Mono CJK JP Regular: официальный файл notofonts/noto-cjk, Sans/Mono/NotoSansMonoCJKjp-Regular.otf; неизменённая копия и лицензия из Sans/LICENSE. Шрифт заменяет MS Gothic с прямого разрешения пользователя.

MS Gothic: оставлен только в локальных исследовательских копиях предыдущей реализации. Не используется новым кодом и не включается в архивы распространения 0.2.0.

OBS SDK и тестовая OBS 32.2.2 — OBS Project, GPL-2.0-or-later. Полная тестовая OBS, SDK и компилятор не включаются в клиентский пакет. Для исходников предоставлены ссылки и скрипт получения зависимостей с контрольными суммами.

llvm-mingw — официальный релиз mstorsjo/llvm-mingw 20261006; его лицензии сохраняются в tools при получении зависимостей. FFmpeg использован только для тестового медиа и не входит в плагин.

Тестовое видео с цветком построено из копии предоставленной автором графики. В публичный клиентский архив и архив исходников тестовая личная графика и ролики не включаются.

Cross-platform preview: portable glyph rasterization uses FreeType 2.13.3 (FTL notice in installer/native/licenses). The graphical setup uses dynamically linked Qt 6 (LGPLv3/GPLv3 notices in installer/native/licenses). CMake infrastructure derives from obsproject/obs-plugintemplate commit 3e7d7ac3b5342cd7d9b88890b9c70b472d1520fc, GPL-2.0-or-later. See CROSS_PLATFORM.md for dependency sources and distribution requirements.
