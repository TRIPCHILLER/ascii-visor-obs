# 0.2.8 — эксперимент со стабильностью символов

Это отдельная тестовая сборка. Публичный черновик 0.2.6 не заменён.

Исторический механизм найден в ascii-miniapp-main 3.55/ascii.js: ROTATE_PALETTE=true, PALETTE_INTERVAL=320, CHANGES_PER_TICK=1; раз в 320 мс выбирается случайный нефиксированный бин и другой символ из него. Это символьная палитра, не цвета.

В исследованных 5.0, 5.2, Windows Beta и коде OBS 0.2.6 этот таймер не активен. OBS 0.2.6 на неизменном тестовом изображении дал 100 одинаковых кадров в каждом из трёх наборов. Это исключает автономную ротацию в данных проверках, но не объясняет само по себе все изменения на живом входе.

При чередовании яркости 127/128 из 255 детерминированное округление индекса символа даёт 28 переключений за 28 соседних сравнений. Это воспроизведено без камеры. В 0.2.8 добавлено удержание предыдущего символа в небольшом диапазоне вокруг его ступени: граница 0.75 ступени вместо обычной 0.5. Никакого размытия изображения или случайного выбора символов нет.

«Стабильные символы» включены по умолчанию. Выключение возвращает обычный выбор по округлению. Контрольные кадры выключенного режима совпали с 0.2.6 по хешам. Включённый режим дал ноль переключений на тесте 127/128, а белый/чёрный вход изменил результат сразу.

Проверьте оба режима на живой камере:
1. Оставьте VISOR включённым только на камере.
2. При одинаковых настройках запишите 5–10 секунд с выключенной стабилизацией.
3. Включите «Стабильные символы» и запишите ещё 5–10 секунд.
4. В каждой части сначала оставайтесь неподвижным, затем двигайте рукой и головой.
5. Сравните мерцание и реакцию на движение. Стабилизация может немного задерживать переход к соседней ступени яркости; это компромисс, который нужно оценить на реальном видео.

Эта сборка не меняет шрифт и метод рисования символов. Чёткость исследуется отдельно. В исходной записи камера отдаёт 1280×720, а выход OBS — 1920×1080, что добавляет увеличение изображения. Также запись H.264 использует цветовую субдискретизацию 4:2:0. Доля каждого фактора в размытии ещё не установлена.
