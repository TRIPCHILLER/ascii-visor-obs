# Установка ASCII VISOR 0.3.1-rc1

Это версия для проверки перед основным релизом. После публикации установщики будут в разделе **Assets** [страницы релиза](https://github.com/TRIPCHILLER/ascii-visor-obs/releases/tag/v0.3.1-rc1). До публикации тестовые пакеты доступны среди артефактов сборки чернового PR. OBS устанавливается отдельно. Перед установкой и обновлением плагина закройте OBS.

## Windows x64

Скачайте `ASCII-VISOR-0.3.1-rc1-Windows-x64-Setup.exe`. Для обычной и Steam-версии OBS выберите общую установку; для переносной OBS укажите её папку. Установщик создаёт нужные каталоги и сохраняет предыдущий плагин для отката, не заменяя профили и сцены OBS. Проверено с OBS 32.2.2.

При ручной установке распакуйте `Windows-x64-Plugin.zip` во временную папку. Внутри `ascii-visor` находятся `bin/64bit/ascii-visor.dll` и `data/`. Для обычной и Steam OBS скопируйте папку `ascii-visor` целиком в `%ProgramData%/obs-studio/plugins/`. Для переносной OBS скопируйте DLL в `<OBS>/obs-plugins/64bit/`, а содержимое `ascii-visor/data/` — в `<OBS>/data/obs-plugins/ascii-visor/`. Сохраните лицензии рядом с плагином. Не создавайте лишний уровень папок из названия архива.

## Linux x86_64

Скачайте `ASCII-VISOR-0.3.1-rc1-Linux-x86_64-Setup.AppImage`. В свойствах файла разрешите выполнение и откройте его. Выберите подходящую установку OBS: обычную/Steam либо Flatpak. Основа сборки — Ubuntu 24.04 (glibc 2.39); требуется OBS 32.2 или новее. Для старых дистрибутивов понадобится совместимая пересборка. Сборки для ARM Linux здесь нет.

AppImage содержит компоненты Qt для X11 и Wayland. Если недоступен FUSE, можно запустить `./ASCII-VISOR-0.3.1-rc1-Linux-x86_64-Setup.AppImage --appimage-extract-and-run`. Альтернативный `Linux-x86_64-Setup.tar.gz` содержит тот же мастер без встроенной Qt: для него нужны совместимые библиотеки Qt 6 Widgets в системе. Не подмешивайте случайные системные плагины Qt в AppImage.

Для ручной установки распакуйте `Linux-x86_64-Plugin.tar.gz` и скопируйте всю папку `ascii-visor` в `$XDG_CONFIG_HOME/obs-studio/plugins/`, либо в `~/.config/obs-studio/plugins/`, если XDG_CONFIG_HOME не задан. Для Flatpak путь — `~/.var/app/com.obsproject.Studio/config/obs-studio/plugins/`. Версии библиотек и OBS внутри Flatpak должны быть совместимы с плагином; сам выбор Flatpak в мастере не гарантирует совместимость с любой средой.

## macOS · Apple Silicon и Intel

Скачайте `ASCII-VISOR-0.3.1-rc1-macOS-universal-Setup.zip`. Распакуйте, закройте OBS и откройте **ASCII VISOR Setup.app**. Укажите **OBS.app**, обычно `/Applications/OBS.app`. Не разделяйте приложение и его внутренние ресурсы. Установщик и плагин содержат код arm64 и x86_64: отдельные архивы для разных процессоров не нужны.

Плагин рассчитан на macOS 12+ и OBS 31.1+; фактические требования могут быть выше из-за версии OBS или встроенной Qt. Проверки отрисовки выполняются с OBS 32.2.2 на обоих процессорах. Установщик имеет локальную подпись, без Developer ID и заверения Apple. Если macOS блокирует доверенный скачанный файл, используйте разрешение для конкретного приложения в **Конфиденциальность и безопасность → Всё равно открыть**. Глобально отключать Gatekeeper не нужно. Мастер сам подписывает установленный плагин локально.

Для ручной установки распакуйте `macOS-universal-Plugin.zip` и перенесите `ascii-visor.plugin` в `~/Library/Application Support/obs-studio/plugins/`. Это цельный пакет: не извлекайте только исполняемый файл из его внутренностей. Установщик предпочтительнее, поскольку выполняет проверки установки и локальную подпись.

## Включение, обновление и удаление

В OBS выберите видеоисточник → **Фильтры → Фильтры эффектов → + → ASCII ⛶ VISOR**. Язык фильтра соответствует языку OBS; после его смены и после установки перезапустите OBS. Язык установщика выбирается отдельно.

Для обновления закройте OBS и запустите установщик с прежним назначением. При необходимости используйте восстановление предыдущей версии в мастере. Для ручного удаления закройте OBS и удалите только папку или пакет плагина по указанному выше пути; в переносной Windows OBS — DLL и папку данных. Настройки OBS и другие плагины не удаляйте.

Контрольные суммы опубликованы в `SHA256SUMS.txt`. Автоматические архивы GitHub **Source code** содержат исходники, а не установщики. Если фильтр не появился, приложите к сообщению об ошибке ОС, процессор, версию и тип установки OBS, а также журнал OBS без секретов и посторонних личных данных.
