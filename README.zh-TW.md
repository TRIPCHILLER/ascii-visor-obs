![ASCII ⛶ VISOR](docs/media/ascii_visor_preview.png)

**ASCII ⛶ VISOR** 是 [OBS Studio](https://obsproject.com/) 的影像濾鏡外掛，可將攝影機或其他影像來源即時轉換成 ASCII 圖像。選擇字元、調整顏色和密度，讓畫面融入你的場景。效果會立即顯示在預覽中，並套用於錄影或直播。

適用於個性化攝影機畫面、創意直播、音樂演出和影像實驗。

ASCII 頭像也是一種類似 VTuber 的出鏡方式：用風格化形象代替一般攝影機畫面，同時保留即時動作與反應。它能提供一定的視覺隱私，但不保證匿名性：聲音、輪廓和畫面細節仍可能讓人認出你。

## ✨ 主要功能

| 功能 | 用途 |
|---|---|
| **8種預設字元集** | 使用經典 ASCII、其他字元和幾何圖形改變畫面質感。 |
| **自訂字元** | 輸入自己的字元集，創造獨特風格。 |
| **20種配色方案** | 選擇預設風格或調整自己的顏色。 |
| **儲存配色風格** | 每個濾鏡最多儲存20個自訂配色預設。 |
| **透明背景** | 讓字元間隙透明，將畫面疊加在遊戲或影片上。 |
| **圖像調整** | 調整密度、對比、伽瑪、黑白色階、縮放和位置。 |
| **直接在 OBS 中使用** | 透過標準濾鏡面板調整，並用於錄影和直播。 |

密度範圍為**橫向30到150個字元**。字元集與配色方案可獨立選擇、自由組合。

### 🎨 配色風格

同一個影像來源，也能呈現不同氛圍。切換配色方案，或自行選擇字元和背景顏色。

### 🔤 字元集與自訂輸入

保留喜歡的配色，從**8種預設字元集**中選擇。經典 ASCII、其他字母、數字和幾何圖形都有各自獨特的質感。

https://github.com/user-attachments/assets/8ed8da50-d899-492f-a81a-4ccff01a9210

想做出自己的風格？選擇**自訂輸入**，輸入想使用的字元。嘗試不同組合，找到喜歡的效果。

### 🎛️ 即時調整

根據光線和場景中的攝影機畫面大小調整密度與色調。修改會立即顯示在預覽中。

https://github.com/user-attachments/assets/772cb41e-769f-432c-b734-f8f910bb3957

### 🫧 適合場景的透明背景

啟用透明背景後，字元間隙可顯示遊戲、影片或其他場景來源。將 ASCII 攝影機畫面融入直播配置。

透明的是字元之間的空隙，不會自動把人物與房間背景分離。
